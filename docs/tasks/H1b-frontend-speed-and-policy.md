# H1b: a fast self-hosted front end and one input policy

Depends on H1. Read docs/tasks/H1-report.md, docs/reviews/claude-H1-review.md and docs/tree-binary-format.md.

1. **One input policy for both front ends and both commands** (decided by Claude as manager 2026-10-25, under "one approach at a time"; Ben may overrule): `nlc run/build/test` apply the same package limits `nlc parse` applies today (256 files, 16 MiB per file, 64 MiB per package, 1,000,000 tokens per file, 4,000,000 per package, 2,000,000 nodes, the work limit, nesting 1,000), with the same messages and order, in the Rust and the self-hosted front ends alike. Invalid UTF-8 is a syntax diagnostic (status 2) in every command. Update docs/syntax-tree-format.md's command section and DESIGN where it describes compile inputs; tests for each limit at N and N+1 under both front ends and commands. The self-hosted front end's storage then needs exactly these limits (lower its 4,096-file and +1 capacities to the policy).
2. **Per-call overhead:** profile the ~250 ms fixed cost per call (cache-key computation, child startup and stack reservation, temp file handling) and remove it: compute the expensive parts of the cache key once per nlc build (a build id embedded at compile time, the runtime and selfhost sources hashed once and recorded with the cached artifact, checked by size and modification time first), avoid re-hashing on every call. Target: a small package within 20 ms of the Rust front end.
3. **Wire size and reading:** make the format compact (variable-length integers, spans as deltas from the parent or previous sibling, no duplicated data the reader can derive), stream it through a pipe instead of a temporary file if that's faster, and rebuild the AST in one pass without holding the whole wire and the AST plus copies at once. Bump the wire version. Targets: under 8 bytes of wire per source byte on the benchmark, parent peak memory within 1.5 times the Rust front end's, and the benchmark within 1.5 times the Rust front end end to end (best of 5).
4. Keep differential AST equality and both full suites passing; rerun H1's malformed-wire and cache tests.
- Report: docs/tasks/H1b-report.md, with before/after numbers and a recommendation on the default.

# Sol: T08/T09 review, round 1

1. **T08, Globals: backing policy is underspecified.** DESIGN “Static allocation” requires effective cgroup limits, configured job headroom and startup page touching; checking overcommit mode and mapping alone is insufficient. Specify headroom configuration, ancestor-limit handling and refusal when backing cannot be established. Keep `locked` optional by refusing unsupported configurations. Make `--allow-overcommit` an explicit guarantee waiver visible at runtime and in inspection. Test policy branches with injected platform readings, including refusal before `main`, rather than only an artificial size limit.

2. **T08, Initialisation: define the runtime source and dependency order.** With configuration effects excluded, what makes an initializer nonconstant? Answer: permit reads of completed globals, order initialization by transitive dependencies through helpers, reject cycles and self-reads, and prohibit startup writes to other globals. Global-reading helpers are not T05-cacheable, even without `print`. Test forward dependencies, indirect cycles, transitive effects, once-only startup evaluation and constant/native agreement. Explicitly defer configuration reading.

3. **T08, Globals: hidden accesses can violate T04/T06 overlap.** Passing `app.items` as `write` to a helper that also reads it by global name creates overlapping access. A helper can likewise remove an element beneath a live view without receiving the collection. Infer transitive global read/write paths; check them against arguments and live views, including T09 indirect calls and comparators. Test both bypasses and a permitted disjoint-field access. Include program-state access in function contracts, as DESIGN requires.

4. **T08, Initialisation: invariants introduce an unscheduled language feature.** T04 explicitly deferred whole-value invariants; T06/T07 do not add them. Split invariant syntax/checking into a prerequisite covering locals, globals, defaults, completed-value publication and subsequent writes. Merely checking startup would conflict with DESIGN’s every-write rule. Test missing required fields, overridden defaults, self-field reads, valid/invalid completed values and post-startup violations; distinguish constant build failures from startup failures.

5. **T08, Collections: preserve T07’s recursive pool restrictions.** “All are values” must not permit pools inside map values, queue/ring elements or grid cells, including through structs. Permit a global struct’s pool field with owner `app.nodes`; initialize it in place without allowing pool-valued constants, copies, returns or enclosing-struct resets. Test local ids escaping into globals through nested containers, legal global ids in local collections, and resetting a global pool through its enclosing struct.

6. **T08, Map/set: ids are missing key types.** DESIGN “Who owns state” explicitly uses `set<units.Id, 500>`. Include owner-typed ids and aggregates containing them; compare/hash slot and generation while checking owners statically. Hash logical fields, never padding. Define update as preserving order, removal as deleting that position, reinsertion as appending. Test collisions, repeated updates, remove/reinsert and a table filled with tombstones; every probe must terminate within a fixed bound.

7. **T08, Map/set views need their own contract.** Specify `for v, k in m` and `for k in s`; keys are immutable, values follow T06 writable-view rules. Choose stable entry storage with separate hash/order metadata; otherwise insertion or deletion can relocate a viewed value. Conservatively reject structural mutations under any nested view, and reject replacing a viewed value or its enclosing storage. Test key-write rejection, legal value-field writes and nested-container invalidation, including helper calls.

8. **T08, remaining collection contracts are incomplete.** Specify constructors/defaults and loop forms. Choose set `add -> Result<(), Full>` (duplicates succeed), set `remove -> bool`, ring `push -> ()`, queue/ring `pop/peek -> Option<T>` copies, and refined-long counts. Empty bounded containers need no element default; grids require defaults/fill evaluated once. Carry constant capacities, overflow checks and metadata-inclusive 64 KB limits forward. Define zero-capacity ring pushes as dropping the input. Permit non-overwriting appends during iteration, reject ring overwrites and queue pops under views. Test wraparound, zero capacities, nested layout, read-only mutation and both grid coordinates failing before stores.

9. **T09, exact matching conflicts with DESIGN’s upper-bound contract.** Keep parameter types/modes and results invariant; accept effects within the declared bound, including a pure function in a print-permitting slot. Give concrete effect-type syntax. Indirect call edges must include every compatible address-taken function, including widened assignments, rather than only exact matches. Test that widening cannot hide recursion, transitive printing or global access; explicitly defer suspension, append and data-stack contracts.

10. **T09, sorting silently requires general type generics.** T07 adds only owner/capacity parameters. Split sorting after function values and a generic-helper prerequisite, or implement compiler-specialized builtins without exposing general generics. State specialization limits and whether concrete owner-typed signatures are allowed; rejecting only `fn<P>` leaves this unresolved.

11. **T09, sorting needs bounded execution/storage decisions.** Use iterative merge sort because T01 forbids recursion. Count scratch and hidden copies under T06’s limit even for global inputs; reject oversized specializations until M3. Require a strict weak ordering and prohibit comparator writes overlapping the input, including global access. Test arrays, all natural-order types, stability across merges, scratch-limit rejection and overlapping context.

12. **T09, missing acceptance contracts.** Choose first matching index for duplicate binary-search keys; require sorted input explicitly. Test duplicates and boundary misses. Add returned function values, identity equality, printing, array storage, anonymous-function rejection and missing function-field initialization: there is no implicit null function.

13. **Split T08’s delivery.** Separate globals/backing/inspection from hash collections and FIFO/grid collections. Each collection slice needs compile-time/native agreement, failure leaving contents unchanged, `discard`/proven-success cases and explicit printing/equality. Choose map/set equality by membership and mapped values, independent of insertion order; print in iteration order. Inspection must count metadata/alignment and exclude local storage from the startup claim; defer entry-point stack reporting explicitly to M3.
